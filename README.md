### 🚀 Projetos em Destaque

#### 🧒 [Kids9 — SaaS B2B de Gestão e Segurança Infantil](https://github.com/pedro-oliveira/kids9)
> Plataforma completa desenvolvida para modernizar a operação e segurança de brinquedotecas, buffets e centros recreativos infantis.
> - **Controle Operacional:** Check-in ágil, monitoramento de permanência e painel em tempo real para TV com alertas visuais.
> - **Segurança Crítica:** Liberação exclusiva via **PIN efêmero de 4 dígitos** gerado dinamicamente e disparado via WhatsApp API ao responsável.
> - **Stack:** Node.js, Express, PostgreSQL, Docker Compose, WAHA (WhatsApp API), TailwindCSS.

#### 🐕 [Brasil Caramelo — Microsserviços e Rede Descentralizada](https://github.com/pedro-oliveira/brasil_caramelo)
> Arquitetura híbrida moderna e escalável, unindo robustez de banco relacional a protocolos descentralizados e pagamentos instantâneos.
> - **Microsserviços em Docker:** Orquestração de 8 contêineres incluindo Next.js 16 (App Router), React 19, Caddy (SSL automático), Meilisearch (busca full-text), Redis (cache/rate-limit) e LiveKit (salas de áudio/WebRTC).
> - **Stack:** Next.js 16, React 19, TypeScript, PostgreSQL, Prisma ORM, Redis, Nostr Protocol.
